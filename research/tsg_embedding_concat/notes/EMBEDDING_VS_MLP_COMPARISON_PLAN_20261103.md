# Embedding 对结构化 MLP 的配对方案

本阶段主要问题是，同一批可用事实通过冻结 Qwen3-Embedding 表示后，是否比字段绑定的结构化数值输入经过 MLP 更有预测价值。动态与常态的差异保留为次级问题。

第三轮完整融合下，动态 Embedding 的四任务平均 VAL NMAE 为 0.351138，结构化 MLP 为 0.355499。两组均在 2176 步选中。Embedding 点估计改善 1.23%，同一步仅 8/20 次领先，配对区间跨零。第四轮动态拼接 Embedding 达到 0.347004，和第三轮动态结构化 MLP 的所选点差 2.39%，同时改变了融合方式，同一步仍仅 8/20 次领先。这两份结果都保留为证据。

最小后继只需补一组动态结构化 MLP＋拼接。保留原字段绑定结构化动态缓存、原 schema 投影与非线性输出层，同时将融合向量设为 LayerNorm(W4[SiLU(W1[s,p,v]),0])。与第四轮动态 Embedding＋拼接按 SHA 复用的对照相比，两组使用同一批事实和起点、同一主模型、拼接融合、训练配方、预算与统一选模。结构化 MLP 保留原有额外 16,384 个参数，比较对象是两种完整表示方案。第四轮 Embedding 原有归档、预注册规则和结果保持封存。

2027 筛查预算为 3 步资格及 2560 步正式更新。四任务完整验证资产宏 NMAE 取均值，按原 128 步候选网格独立选出各自一个 checkpoint。以 Embedding 的均 NMAE 至少低 0.5%、至少三项任务改善为实用门槛。共同训练步和末段结果用于检查方向是否反转，使用按预测起点配对的七日分块区间报告不确定性。全部 16 项指标及分任务、资产和时段差异一并保留。该次筛查使用已反复检验的 2027 验证集，独立确认需先固定方案，再授权独立种子或留出数据。
