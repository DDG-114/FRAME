# TSG Embedding 与拼接控制路线

本分支记录当前 TSG 候选路线及其配对证据。共享预测器服务负荷、风电、光伏和净负荷。每个预测窗口从可用历史和已发布的预报中构造显式运行事实，经冻结 Qwen3-Embedding-8B 编码。编码取最后有效 token 的末层状态，以 FP32 做 L2 归一化。语义向量、历史数值摘要和字段可用性通过拼接构造控制向量，控制各层低秩残差的成分权重和修正幅度。

主比较固定同一批动态事实、预测接口和拼接融合。Embedding 组使用 `concat_only`，结构化 MLP 组使用 `mlp_schema_concat`，保留字段绑定输入和原有 MLP 投影。两组都关闭乘积项，使用种子 2027、2560 次正式更新，以及完整四任务 VAL 资产宏 NMAE 的统一选模规则。

| 同事实、同拼接配置 | 所选步 | 四任务平均 VAL NMAE |
|---|---:|---:|
| Qwen3-Embedding-8B | 2176 | 0.347004 |
| 结构化 MLP | 2560 | 0.358144 |

Embedding 相对 MLP 改善 3.11%，四项任务的 NMAE 均降低。共同训练步领先 13/20，末八步领先 5/8，终点落后 5.46%。七天按预测起点配对的分块区间为 −0.24% 至 +6.47%。目前的比较属于单种子探索性验证。历史粗事实拼接的 0.342964 仍是更强的平均 NMAE 参考。

普通 Qwen3-8B 版的数值协议、共享骨干、逐层残差设计和消融设置是这条路线的基础。旧编码器、旧拼接和旧门控结果以各自原配方具名对照。直接比较普通 8B 和 Embedding 仍需要补一组普通 8B 使用同一份显式事实与拼接控制的实验。Table I 与 SMARD 的主模型结果如改用 Embedding，应由对应 checkpoint 重新评估。原字段级 CAISO 研究可单列。

## 分支内容

- `predictor/` 保存已登记预测器和训练入口的源码快照。
- `fact_encoding/` 保存事实构造、结构化表示和冻结 Embedding 编码的源码快照。
- `evidence/` 保存已归档的配对决策、四任务指标和全部 20 个共同候选步的结果。
- `notes/` 保存匹配方案及拼接消融分析。各源码与结果文件的来源及 SHA-256 见 `PROVENANCE.json`。

在本目录进入 `predictor/`，安装兼容的 PyTorch 和 NumPy 后，可运行 `python -m unittest test_paper_model -v` 检查模型与训练基础组件。完整复训需要原四任务数据包及其协议文件、两套已审计缓存、原实验的注册和准备清单。完整事实编码需要对应的文本、字段映射、模型权重和实验配置。这些外部资产继续由原实验归档管理。
