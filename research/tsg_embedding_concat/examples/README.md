# 合成风电数据案例

在本目录运行下列命令生成两组 JSON 数据，只需要 Python 3。

    python wind_availability.py > wind_availability.json

两组采用同一个预测起点（10:00 UTC），每 10 分钟一条观测。
过去 24 小时窗口不含左端点，包含预测起点。延迟组的 09:50 和
10:00 观测都在 10:10 到达。

| 情况 | 最新可用观测 | 末三位掩码 | 24 小时有效点数 | 观测年龄 |
|---|---|---|---:|---:|
| 正常 | 10:00 | true, true, true | 144 | 0 分钟 |
| 延迟 | 09:40 | true, false, false | 142 | 20 分钟 |

到达时间决定观测在预测起点是否可用。最新可用观测的采集时间与
预测起点之差就是观测年龄。JSON 中缺测功率为 null，数值模型
用零填充和 false 掩码表示该位置。availability_text 展示对应的
两个事实文本字段。

示例的功率单位是 kW，覆盖目标历史和可用性字段。完整模型输入还
包含其他历史通道、已知未来条件及其掩码、任务和采样频率。
